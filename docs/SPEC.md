# MVP Specification — «Саммари официальных документов»

## Источник требований

Главный источник истины — официальное задание хакатона «САММАРИ официальных документов», полученное 18.09.2026.

## Must

### A. «Точечный детектив» — приоритет
- ситуационный вопрос на естественном языке;
- поиск по актуальным версиям документов;
- дословная цитата + документ + версия;
- понятное объяснение без выхода за найденные нормы;
- явное обнаружение противоречий;
- выбор приоритета только при наличии явных метаданных;
- если нормы нет: «В предоставленных документах это не урегулировано. Рекомендуем обратиться к HR-партнёру».

### B. «Навигатор по структуре»
- загрузка TXT/MD/CSV/JSON/DOCX/PDF;
- структурированная выжимка: тема, аудитория, требования, запреты, права;
- сравнение с предыдущей версией, если версия известна корпусу;
- обязательная кнопка скачивания выжимки.

## Сквозные требования
- prompts.json редактируется без пересборки;
- версионность документа учитывается локально;
- безопасность — вторичный слой: псевдонимизация/маскирование/блокировка credentials; целевая схема ACL/RBAC до retrieval;
- основной UI ориентирован на non-tech пользователя;
- AI не является единственной точкой отказа: при недоступности LLM есть явно маркированный deterministic fallback.

## Не входит в hackathon MVP
- production SSO/RBAC enforcement;
- постоянная vector DB;
- микросервисы;
- production deployment;
- OCR сканов;
- полноценный граф перекрёстных ссылок;
- bonus-карта эмоционального тона.
